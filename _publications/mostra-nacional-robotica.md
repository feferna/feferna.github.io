No presente trabalho é mostrado o desenvolvimento e os resultados obtidos no estudo sobre o uso de redes neurais para a resolução da cinemática inversa de manipuladores robóticos, mais precisamente para o caso de um manipulador com 5 graus de liberdade. A cinemática inversa é um ramo com grandes desafios devido ao problema das equações não serem lineares, dificultando a determinação de soluções de uma forma fechada. Portanto, diversos pesquisadores, ao longo dos anos, tentam resolver esse problema evitando o uso de inversões de equações. Nesse sentido, o uso de Redes
Neurais Artificiais se mostra uma alternativa atraente. Para se atingir este objetivo, o estudo foi realizado para o caso de um robô manipulador educacional com 5 graus de liberdade, composto de uma estrutura de alumínio e seis servomotores. Além disso, utilizou-se o MATLAB para o desenvolvimento e treinamento da Rede Neural.
